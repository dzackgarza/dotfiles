# Sway Configuration Notes

This directory contains your Sway configuration.

## Popular GTK Themes for Ricing

Based on community sentiment and common "ricing" practices, here are some highly-regarded GTK themes that offer an elegant and sleek aesthetic:

*   **Orchis GTK Theme:** Modern, clean, Material Design inspired with rounded corners.
*   **WhiteSur GTK Theme:** macOS Big Sur inspired, modern, minimalist with translucence.
*   **Fluent GTK Theme:** Brings Microsoft Fluent Design aesthetic to Linux desktops.
*   **Arc GTK Theme:** A classic, clean, minimalistic flat theme with transparent elements.
*   **Nordic GTK Theme:** Favored for its dark, comforting color palette (Nord color scheme).
*   **Vimix GTK Theme:** Modern design with subtle gradients and clean lines, based on Material Design.
*   **Pop GTK Theme:** Polished and refined, developed by System76 for Pop!_OS.

These themes are installed on your system and can be selected using `lxappearance`.

## Popular GTK Fonts for Ricing

For a consistent and aesthetically pleasing look, the ricing community often recommends these fonts for GTK applications, prioritizing readability and a modern aesthetic:

*   **Noto Sans Medium:** A versatile font known for its comprehensive language support and clean appearance.
*   **Roboto:** A modern, geometric sans-serif font with excellent legibility, highly versatile for UIs.
*   **Inter:** Specifically designed and optimized for screens and user interfaces.
*   **Source Sans Pro:** Designed for maximum legibility and readability on digital displays.
*   **Open Sans:** A widely used and versatile sans-serif font with good readability.
*   **DM Sans:** Offers a clean, modern look, particularly effective for small text sizes in minimalist designs.
*   **Raleway:** A sans-serif font with open letterforms that enhance readability on screens.

These fonts can be set using `lxappearance` after installation.
